# CI/CD Roadmap

Phase 1: Run the application locally.
Phase 2: Push source code to GitHub.
Phase 3: Make GitHub Actions CI pass.
Phase 4: Build and test Docker images.
Phase 5: Push images to Docker Hub.
Phase 6: Create AWS EC2.
Phase 7: Configure continuous deployment.
Phase 8: Add Nginx and HTTPS.

This repository intentionally stops before deployment.
